## Lemborexant: From Insomnia to Sleep Disorder (Initiating and Maintaining Sleep)
{: .text-alpha }

## One-Sentence Summary

Lemborexant is a dual orexin receptor antagonist originally used to treat insomnia.
The TxGNN model predicts it may be effective for **sleep disorder, initiating and maintaining sleep**, which is essentially the same condition as its current use rather than a true new indication.
The prediction is supported by **20 publications**, including Phase 3 randomized trials and several network meta-analyses, but no clinical trials were registered in the data compiled for this report.

## Why is This Prediction Reasonable?

Lemborexant is a dual orexin receptor antagonist (DORA). It blocks orexin OX1R and OX2R signalling, which reduces the brain's wake-promoting drive and helps both sleep onset and sleep maintenance. Detailed mechanism data was not available in the data compiled for this report, but this mechanism is well established in the published literature.

The predicted indication, difficulty initiating and maintaining sleep, describes the same clinical problem as insomnia. This is therefore not a true repurposing case. The very high TxGNN score is consistent with the model recognising a known, on-label use.
